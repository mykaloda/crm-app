# crm-app

## leadgen — ежедневный поиск B2B-партнёров для Lerega

Каждое утро ищет бизнесы в районе Остина, с которыми Lerega может сотрудничать:

| Направление | Кого ищем |
| --- | --- |
| Коммерция | рестораны и бары, отели и площадки, офисы и коворкинги, управляющие недвижимостью и Airbnb, салоны и клиники, дилеры авто/RV/лодок |
| Мебель | дизайнеры интерьера, мебельные магазины, антиквариат и комиссионки, переезды, строители |
| Сумки | ресейл люксовых сумок, ремонт обуви и ателье, химчистки, бутики и свадебные салоны |

- `leadgen/config.py` — сегменты, районы, «что предложить», бюджет кредитов ScrapeGraph.
- `leadgen/find_leads.py` — поиск через ScrapeGraphAI SearchScraper, дедупликация, оценка, таблица.
- `leadgen/from_maps.py` — запасной источник (поиск по картам), когда ScrapeGraph недоступен.
- `leadgen/DAILY_RUN.md` — что делает утренняя сессия.
- `data/leads.csv` — все найденные лиды; `data/daily/ДАТА.csv` — новые за день.
- Google Drive: папка «Lerega — B2B лиды», по таблице на каждый день.

```bash
export SGAI_API_KEY=...            # ключ ScrapeGraphAI
python3 leadgen/find_leads.py check   # проверить ключ и остаток кредитов
python3 leadgen/find_leads.py plan    # что будет искаться сегодня
python3 leadgen/find_leads.py search  # найти и добавить новые лиды
```

Бюджет по умолчанию: 4 поиска × 5 сайтов = ~200 кредитов ScrapeGraph в день (`QUERIES_PER_DAY`, `SITES_PER_QUERY`).
